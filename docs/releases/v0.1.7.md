## Summary

This release makes deleting safer: a copy you keep is no longer deleted when it has the same file name as the deleted one, and a torrent now stays in qBittorrent when no other torrent has the same file.

## Bug fixes
• **Deletion**: a kept copy with the same file name is no longer deleted
• **qBittorrent**: a torrent is kept when no other torrent has the same file
