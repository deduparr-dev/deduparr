## Summary

Deduparr can now scan on a schedule: set it up in Settings, and get an email when a scan finishes. Scheduled scans also no longer fail to sign in to Plex, and deleting works better alongside qBittorrent and when Plex sees your files in another folder.

## Bug fixes
• **Scheduled scans**: no longer fail to sign in to Plex
• **Setup wizard**: the libraries you pick now work with scheduled scans
• **Deletion**: finds the file even when Plex sees it in another folder
• **qBittorrent**: deleting a duplicate no longer fails with a "last copy" error

## Enhancements
• **Scheduled scans**: set them up in Settings, daily or every few hours
• **Scheduled deletion**: can be set up in Settings, but deletes nothing until 0.6.0
• **Email notifications**: get an email after each scheduled scan and deletion
• **qBittorrent**: finds the matching torrent for more duplicates
• **Security**: passwords, keys and tokens are hidden from logs and web addresses
