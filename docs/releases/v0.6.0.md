## Summary

Deduparr now works with Jellyfin, on its own or next to Plex, and can delete every pending duplicate at once. Deleting is also much safer: it no longer touches other titles, the copy you keep or your library folders, and a deletion that fails now says so.

## Breaking
• **API scripts**: send `libraries` per server instead of `library_names`, and read `item_id` instead of `plex_item_id`

## Bug fixes
• **Deletion**: another title's files with the same name are no longer deleted
• **Deletion**: the copy you keep can no longer be deleted with its duplicate
• **Season packs**: deleting one episode no longer deletes the rest of the pack
• **Subtitles**: subtitles and extras that other episodes use are no longer deleted
• **Library folders**: a library folder is no longer removed when its last title goes
• **Scheduled deletion**: deletes for real instead of only pretending to
• **Failed deletions**: now shown as failed, ready to try again
• **Statistics**: a deletion counts as successful once the file is gone
• **Sonarr**: picks up the episode you kept after a deletion
• **Quality profiles**: an unexpected answer from Radarr or Sonarr no longer stops the scan
• **Duplicates found again**: a title that gets a new duplicate after a deletion shows up again
• **Setup wizard**: the Radarr, Sonarr and qBittorrent tests now really test the connection
• **Setup wizard**: finishing it opens the dashboard instead of starting over
• **Container health**: Docker now notices when Deduparr itself stops working
• **Smaller fixes**: connection test messages, the scan summary, saved keys in Settings, Radarr after a deletion, and old databases

## Enhancements
• **Jellyfin**: use Deduparr with Jellyfin, with Plex, or with both
• **Delete all**: delete every pending duplicate in one go
• **Libraries**: pick which libraries to scan on each server
• **Scan results**: each duplicate shows which server it came from
• **Test versions**: the `dev` image now carries the newest changes
• **Under the hood**: Deduparr now runs on Python 3.15
