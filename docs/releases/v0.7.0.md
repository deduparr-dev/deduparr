## Summary

This release makes deleting safe when Plex and Jellyfin are used together, and fixes problems that only showed up against real servers: deleting a file Radarr or Sonarr tracks reported a failure and lost track of the title, and preferring their quality profile never took effect. Saved passwords and API keys are now encrypted, and a schedule saved in Settings survives a restart.

Back up your `/app/data` folder together with your database: without its key file, saved passwords and keys have to be entered again, and an older version cannot read them.

## Breaking
• **Scheduled deletion**: `ENABLE_SCHEDULED_DELETION=true` now really deletes, so check it before updating
• **Scheduled scans**: a time written as `2:00` now stops startup and must be `02:00`
• **Settings export**: an export no longer holds passwords and API keys
• **API**: web pages on another address can no longer call Deduparr

## Bug fixes
• **Deletion**: a title can no longer lose its last copy when Plex and Jellyfin keep different ones
• **Deletion**: a copy you mark to keep on one server is now kept on the other too
• **Deletion**: deleting a file Radarr or Sonarr tracks now works, and they pick up the copy you kept
• **Torrents**: the torrent of a deleted copy now goes with its data, and the kept copy's torrent keeps seeding
• **Quality profiles**: "Prefer *arr Quality Profile" now really uses Radarr's and Sonarr's ranking
• **Scoring**: 4K and scene-named Blu-rays now score as high as they should
• **Setup wizard**: asks which Plex server to use instead of taking the first
• **Scan page**: libraries load on real Plex servers, and every duplicate is reachable with Load More
• **Delete All**: counts each file once, skips sets with nothing to delete, and shows its notes
• **Space reclaimed**: shows what was really freed, which is nothing while a season pack still holds the file
• **Schedule**: a schedule saved in Settings still runs after a restart, and saving keeps a queued deletion
• **Deep scan**: episodes of different shows are no longer called duplicates
• **Logs**: no part of the Plex token or account name is written to the log any more

## Enhancements
• **Security**: saved passwords and API keys are encrypted, and Deduparr never sends them back to the browser
• **Path mappings**: Radarr and Sonarr can see your media under other paths than your media server
