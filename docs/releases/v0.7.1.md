## Summary

This release fixes three problems: a new install with the default Docker setup could not start, a scan interval over a day could stop running on a server restarted more often than the interval, and Plex kept listing a copy Deduparr had deleted.

Two things change when you update. Deduparr now takes ownership of its config and data folders at every start, so set `PUID` and `PGID` if another user should own them. A scan interval over a day now runs on fixed days, whichever day you saved it: every 7 days is always a Saturday.

## Bug fixes
• **Install**: a first start with the default Docker setup no longer stops with a database error
• **Schedule**: a scan interval over a day now runs on time, however often Deduparr restarts
• **Plex**: a deleted copy now disappears from Plex within seconds
• **Smaller fixes**: encrypted values are hidden in the log, and the documentation is corrected

## Removed
• **Example config**: `config/config.example.yml`, which Deduparr never read, is gone
