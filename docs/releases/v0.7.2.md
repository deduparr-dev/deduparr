## Summary

This release stops Deduparr showing finished deletions as if they were still duplicates, and handles a media server that has gone away: logging out of Plex now really logs you out, and a scan tells you when it could not read a server. It also fixes lost results when you have two libraries of the same type.

If you have scripts using the API: a scan that skipped a server or library now answers `success: false`.

## Bug fixes
• **Scan page**: only duplicates still open are listed and counted
• **Dashboard**: the tiles count open duplicates, and finished ones stay under Recent Activity
• **Plex logout**: Logout now signs you out at plex.tv as well, and only opens the setup wizard when no media server is left
• **Scans**: a scan now says which server or library it could not read
• **Settings**: a Plex sign-in that Plex rejects now shows the error instead of "Authenticated"
• **Several libraries**: two libraries of the same type now both keep their duplicates
• **Old servers**: open duplicates from a server you no longer use are removed
• **Scheduled deletion**: nothing is queued after a scan that could not read everything
